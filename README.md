# 拾句 · 文字拼贴诗

把喜欢的文字剪成纸片，重新组合、排版，留下一张自己的诗。

## 直接使用

解压后，用浏览器打开 `index.html` 即可使用。项目不需要安装依赖、账号、API 密钥或服务器。也提供一份将全部资源内嵌的 `shiju.html`，下载后可单独打开。

1. 点选主题词语，或在“剪我的文字”粘贴文章，选中文字后点击“剪成纸片”。也可以直接输入新词。
2. 点击词语加入画布，或用鼠标把词语拖到纸上的指定位置。
3. 拖动纸片排列；选中后编辑文字、字形、字号、纸片边缘和墨色。圆点可以旋转、缩放，右侧也有精确控制。
4. 点击空白处或“完成”，切换整张作品的纸张气氛、比例、落款。
5. 导出高清 PNG，或保存工程，以后继续修改。

手机底部有“画布 / 词语 / 编辑 / 导出图片”快捷栏。手机浏览器若没有下载提示，可在导出弹窗中长按图片保存。

## 已实现

- 四个原创主题词语包：没有寄出的信、夜行与雨、散场以后、去远方。
- 原文手动选词、词语盘、直接补词；同一个词可重复使用。
- 中文、英文、标点、表情和多行文字；自动换行。
- 拖动、旋转、缩放、复制、删除、图层顺序与中心对齐提示。
- 宋体 / 黑体，裁切 / 撕边 / 无底纸，墨色 / 朱红。
- 胶带、划线与印章；三套整体风格；竖版 3:4、方形 1:1。
- 最多 70 个当前会话历史状态；撤销 / 重做，清空与新建确认。
- 本机自动保存、最近有效备份、JSON 工程导入 / 导出。
- 2 倍分辨率 PNG：竖版 1800×2400，方形 1800×1800，无水印。
- 桌面布局与窄屏布局，键盘编辑和可访问的纸片清单。

## 保存与边界

本机存档依赖当前浏览器及当前网址；不同浏览器、不同域名或不同设备之间不会自动同步。清理浏览器数据也可能移除存档。重要作品请主动保存工程。

工程文件包含自己的原文、收集的词语、作品设置和可编辑纸片。导入会先验证整个文件，验证失败不会替换画布；导入已有作品前会提示确认。单个工程上限 2 MB，每张纸片上限 120 字，一张作品上限 120 个元素。

采用设备自带的中文宋体 / 黑体字库；跨设备时字体外观可能略有不同。同一设备的画布预览与 PNG 导出使用同一套绘制代码及字体。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl / ⌘ + Z；Ctrl / ⌘ + Shift + Z |
| 保存工程 | Ctrl / ⌘ + S |
| 移动选中纸片 | 方向键；按住 Shift 每次移动 10 格 |
| 删除 / 复制选中纸片 | Delete；Ctrl / ⌘ + D |
| 取消选中 | Esc |
| 旋转时按 15° 对齐 | 拖动旋转圆点时按住 Shift |

编辑输入框时保留浏览器的文字撤销行为。

## 开发与验证

核心文件是 `index.html`、`styles.css`、`engine.js`、`app.js`、`favicon.svg`，全部为原生 HTML / CSS / JavaScript，无第三方运行依赖、远程字体或网络请求。

`engine.js` 负责文字测量、自动换行、几何边界、命中检测、工程校验和绘制；`app.js` 负责交互、存档、历史、导入导出。

运行核心测试：

```sh
node --test tests/engine.test.cjs
```

已通过真实浏览器操作验证：新建、加词、原文选词、多行与样式编辑、复制删除撤销、拖动、旋转、比例和主题切换、PNG 实际下载、工程实际下载并重新导入、刷新恢复。窄屏在 390px / 320px 的同源 iframe 视口中检查；未进行实体手机或 Safari 测试。

## GitHub Pages 部署

本项目可直接部署为静态网站。在仓库 Settings → Pages 中选择 Deploy from a branch，使用 `main` 分支的 `/(root)` 目录并保存即可，不需要构建命令。根目录的 `.nojekyll` 用于跳过 Jekyll 处理。
